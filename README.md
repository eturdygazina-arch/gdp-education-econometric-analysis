# GDP and Higher Education Analysis in Kazakhstan

## Overview

This project investigates the relationship between higher education and gross regional product (GRP) per capita across regions of Kazakhstan.

The study examines whether regions with a higher number of university graduates tend to demonstrate higher economic performance.

## Research Question

Does a higher level of education contribute to higher regional economic output in Kazakhstan?

## Dataset

The dataset contains regional statistics from Kazakhstan, including:

* Gross Regional Product (GRP) per capita
* Number of university graduates
* Unemployment rate
* Labor force participation rate
* Employment level
* Urbanization indicators

Data were collected from official statistical sources.

## Methods

* Simple Linear Regression
* Multiple Linear Regression
* Correlation Analysis
* Multicollinearity Assessment
* Gauss-Markov Assumption Testing
* Model Evaluation using F-tests and t-tests

## Key Findings

* A positive relationship was found between the number of university graduates and GRP per capita.
* Education remained the most statistically significant factor in the final regression model.
* The final model achieved a higher explanatory power after removing multicollinear variables.
